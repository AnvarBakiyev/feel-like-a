# Как перепроверить эпизод «машинист»

Всё, что показано на странице игры, можно пересчитать на своей машине. Нужен только Python 3.10+ (стандартная библиотека) и, для теста браузерной версии, Node.js. Ключи, сеть и Extella для перепроверки не нужны: ответы моделей лежат в журналах как есть, а счёт заново считает открытый симулятор.

```bash
cd train
python3 test_sim.py          # 8 тестов симулятора: зерно, скрытое, правила, расписание, язык поездки
python3 test_replay.py       # пересчёт рейса по журналу решений (для таблицы рекордов); подделка отклоняется
python3 web/make_parity.py && node web/parity.mjs   # браузерный sim.js совпадает с sim.py до последнего знака
python3 verify.py            # все опубликованные счёты из записанных решений, около 10 минут
```

`verify.py` печатает таблицу средних и сравнивает каждый пересчитанный счёт с записанным:

| что пересчитывается | откуда решения | как |
|---|---|---|
| Extella, язык поездки v2, 30 рейсов | `extella/runs_v2/*.json`, поле `plan` | тем же обработчиком `poezdka.run` в мире зерна |
| малая модель без Extella (Qwen 9B), 30 рейсов | `extella/noext/small_*.json`, поле `plan` | план контроллера по км исполняется буквально (`noext.execute`) |
| большая модель без Extella (Claude), 30 рейсов | `extella/noext/big_*.json` | так же |
| большая модель с обратной связью (Claude), 9 рейсов | `extella/noext/closed/*.json`, поле `acts` | действия проигрываются заново (`closed.replay`) |
| простые программы (не ИИ) `full` и `careful` | код `drivers.py` | считаются заново на зёрнах 1–10 |

Ответ последней проверки (12.11.2026): все счёты совпали.

| средний счёт | Германия | Готард | Япония |
|---|---|---|---|
| Extella | 578 | 852 | 719 |
| малая модель без Extella | −4 370 | −7 686 | −27 718 |
| большая модель без Extella | −150 | −60 | −348 |
| большая модель с обратной связью (рейсы 1–3) | −225 | 744 | 241 |
| простая программа `full` | 619 | 357 | 748 |
| простая программа `careful` | 569 | 792 | 660 |

## Что нельзя перепроверить без моделей

Сами ответы моделей. Чтобы получить их заново, нужны Ollama с `qwen3.5:9b` (`extella/player.py`, `extella/noext.py small`) и, для Extella, ключ и устройство на Extella (`extella/extella_call.py`, эксперт `train_plan` собирается `extella/build_expert.py` из `sim.py` и `poezdka.py`). Большая модель вела поезд как субагент Claude через `extella/closed.py`; подсказки большой модели записаны в `extella/noext/PROMPTS.md`. Модели с temperature 0 на той же машине дают те же ответы, но на другой сборке Ollama могут отличаться: поэтому мы храним ответы, а счёт пересчитываем.

## Как устроено сравнение

Подробно на странице игры, урок «Как играет Extella». Коротко: один и тот же рейс (погода, ремонт, задержка, поезд впереди задаёт зерно), одна формула счёта. Extella и модели без Extella видят один брифинг; модели без Extella пишут контроллер по километрам сами, и он исполняется буквально; большая модель с обратной связью видит кабину и решает по ходу рейса, как человек. Предсказания писались до прогонов: `PREDSKAZANIYA.md`, там же все несбывшиеся и правки окружения по ходу.
